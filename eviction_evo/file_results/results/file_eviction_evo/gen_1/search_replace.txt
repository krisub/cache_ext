<DESCRIPTION>
The current policy is over-protective, leading to cache thrashing and high p99 latencies. The key issues are:

1. **Too generous time windows**: RECENT_ACCESS_NS (100ms) and WORKING_SET_NS (1s) protect too many pages
2. **Too low hot threshold**: HOT_ACCESS_THRESHOLD=3 marks too many pages as hot
3. **Binary priority decisions**: HIGH_PRIO_NICE_MAX=0 doesn't differentiate between nice=-10 and nice=-1, or between nice=5 and nice=15
4. **Weak adaptation to priority changes**: In file_niceness where priorities flip mid-run, the policy relies on stale accessor_nice values

This edit implements a more nuanced priority-weighted eviction strategy:

1. **Tighten time windows**: Reduce RECENT_ACCESS_NS to 50ms (more realistic for active working set) and WORKING_SET_NS to 500ms (reduce over-protection)
2. **Increase hot threshold**: Raise HOT_ACCESS_THRESHOLD to 5 (be more selective)
3. **Add granular priority tiers**: Instead of binary high/low priority, distinguish between very high (nice<=-5), medium (nice<5), and low priority (nice>=5)
4. **Priority-weighted age thresholds**: Low-priority pages can be evicted with shorter age, while high-priority pages get more protection
5. **Strong eviction signal for low-priority old pages**: Aggressively evict pages from low-priority processes that haven't been accessed in 200ms

This approach should:
- Reduce thrashing by being less protective overall
- Better differentiate between priority levels
- Adapt better when priorities change (by evicting low-priority pages faster)
- Improve file_niceness throughput (the weaker trace) more than it hurts file_priority
</DESCRIPTION>

// -- Eviction iteration callback ----------------------------------------------
static int bpf_evict_cb(int idx, struct cache_ext_list_node *node)
{
    u64 now = bpf_ktime_get_ns();
    u64 key = (u64)node->folio;

    struct sched_folio_metadata *meta =
        bpf_map_lookup_elem(&folio_metadata_map, &key);

    if (!meta)
        return CACHE_EXT_EVICT_NODE;

    if (folio_test_dirty(node->folio) || folio_test_writeback(node->folio))
        return CACHE_EXT_CONTINUE_ITER;

    // -- Priority-weighted eviction strategy ----------------------------------
    u64 age_ns = now - meta->last_access_ts;
    bool recently_used  = age_ns < RECENT_ACCESS_NS;
    bool in_working_set = age_ns < WORKING_SET_NS;
    bool is_hot         = (meta->access_count >= HOT_ACCESS_THRESHOLD);

    // Priority tier classification
    bool very_high_prio = (meta->accessor_nice <= VERY_HIGH_PRIO_NICE);
    bool low_prio       = (meta->accessor_nice >= LOW_PRIO_NICE);

    // Protect very recent accesses (any priority)
    if (recently_used)
        return CACHE_EXT_CONTINUE_ITER;

    // Strongly protect hot pages from very high-priority processes
    if (is_hot && very_high_prio && in_working_set)
        return CACHE_EXT_CONTINUE_ITER;

    // Aggressively evict old pages from low-priority processes
    if (low_prio && age_ns > LOW_PRIO_AGE_NS)
        return CACHE_EXT_EVICT_NODE;

    // When CPU is busy, prioritize very high-priority process pages
    if (sched_nr_running > 4 && very_high_prio && in_working_set)
        return CACHE_EXT_CONTINUE_ITER;

    // Protect hot pages in working set (medium priority or higher)
    if (is_hot && in_working_set && !low_prio)
        return CACHE_EXT_CONTINUE_ITER;

    // Evict cold pages (low access count) that are older than working set
    if (meta->access_count < 3 && age_ns > WORKING_SET_NS)
        return CACHE_EXT_EVICT_NODE;

    return CACHE_EXT_CONTINUE_ITER;
}
