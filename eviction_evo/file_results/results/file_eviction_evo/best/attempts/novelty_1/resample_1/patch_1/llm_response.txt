<DESCRIPTION>
The recommendation suggests implementing a "demotion" mechanism to prevent cache pollution in the high-priority list from one-time accesses by high-priority processes.

**Rationale:**
- Currently, single-access folios from high-priority processes consume slots in the high-priority list indefinitely (as long as they're within WORKING_SET_NS)
- These one-time accesses prevent the high-priority list from protecting truly *hot* (multi-access) data
- The file_niceness workload (2510.52) is slightly weaker than previous iterations despite excellent file_priority performance (3285.09)
- Demoting single-access high-priority folios after they age past WORKING_SET_NS*2 (600ms) will:
  1. Free high-priority cache slots for frequently-accessed data
  2. Allow single-accesses to be evicted more aggressively from low-priority list
  3. Improve working set efficiency without hurting high-priority hot pages

**Implementation:**
In `bpf_evict_high_prio_cb`, before applying retention rules for hot/recent pages, check if a folio is a single-access candidate for demotion. If `access_count == 1` and `age > WORKING_SET_NS * 2`:
- Delete the folio from the high-priority list
- Add it to the low-priority list
- Return CONTINUE_ITER (don't evict, just demote)
- Bump a counter to track demotions

This prevents one-time accesses from monopolizing high-priority slots while giving them a reasonable grace period (600ms) before eviction from the low-priority list.
</DESCRIPTION>

// -- Eviction callback for high-priority list (protect aggressively) --------
static int bpf_evict_high_prio_cb(int idx, struct cache_ext_list_node *node)
{
    u64 now = bpf_ktime_get_ns();
    u64 key = (u64)node->folio;

    struct sched_folio_metadata *meta =
        bpf_map_lookup_elem(&folio_metadata_map, &key);

    if (!meta)
        return CACHE_EXT_EVICT_NODE;

    // Never evict dirty/writeback pages
    if (folio_test_dirty(node->folio) || folio_test_writeback(node->folio))
        return CACHE_EXT_CONTINUE_ITER;

    u64 age = now - meta->last_access_ts;

    // Very hot folios: protect aggressively
    if (meta->access_count >= VERY_HOT_ACCESS_THRESHOLD) {
        if (age < WORKING_SET_NS * 3)
            return CACHE_EXT_CONTINUE_ITER;
    }

    // Hot folios from high-priority processes: protect well
    if (meta->access_count >= HOT_ACCESS_THRESHOLD) {
        if (age < WORKING_SET_NS * 2)
            return CACHE_EXT_CONTINUE_ITER;
    }

    // Small files from high-priority: extend protection window
    bool is_small = should_protect_small_file(node->folio);
    if (is_small) {
        if (age < WORKING_SET_NS * 2)
            return CACHE_EXT_CONTINUE_ITER;
    }

    if (sched_nr_running > CPU_BUSY_THRESHOLD) {
        if (age < WORKING_SET_NS)
            return CACHE_EXT_CONTINUE_ITER;
    }

    // Recently accessed: protect
    if (age < RECENT_ACCESS_NS)
        return CACHE_EXT_CONTINUE_ITER;

    // Only evict if very old
    if (age < WORKING_SET_NS)
        return CACHE_EXT_CONTINUE_ITER;

    return CACHE_EXT_EVICT_NODE;
