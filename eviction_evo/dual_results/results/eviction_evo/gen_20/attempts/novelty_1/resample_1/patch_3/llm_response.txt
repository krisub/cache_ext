<DESCRIPTION>
The current burst detection uses a fixed 5ms threshold (`BURST_THRESHOLD_NS`) which may cause false positives during sustained high-throughput periods (incorrectly treating normal high-rate traffic as bursts and over-protecting folios) or false negatives during variable-rate workloads (missing actual bursts when inter-arrival times fluctuate around the threshold).

Looking at the performance data, the best-performing program (324.29 score) uses simpler tier-specific windows without complex burst detection, suggesting the current burst logic may be adding overhead without proportional benefit. However, the concept of burst detection is valuable - it just needs to be more adaptive.

This edit implements an adaptive burst threshold based on a rolling average of recent inter-arrival times. The approach:

1. Maintains a small array (8 entries) of recent inter-arrival times as global variables within the EVOLVE-BLOCK
2. Computes a rolling average of these times when checking for bursts
3. Sets the burst threshold dynamically to 1.5x this average (with bounds: 3ms min, 8ms max)
4. Updates the history on each burst check to track recent patterns

The bounded adaptive threshold (3-8ms) prevents extreme values while allowing the policy to distinguish true bursts (requests arriving much faster than recent average) from steady high-rate traffic. This should improve both dual_small_vs_large (by not over-protecting during the fast reader's steady stream) and dual_congested (by correctly identifying bursts despite network delays).
</DESCRIPTION>

// -- Helper: Update inter-arrival history and compute adaptive burst threshold --
static __always_inline void update_inter_arrival_history(u64 inter_arrival_ns) {
    // Store in circular buffer
    u32 idx = inter_arrival_index % 8;
    inter_arrival_history[idx] = inter_arrival_ns;
    inter_arrival_index++;
}

static __always_inline u64 get_adaptive_burst_threshold(void) {
    // Compute rolling average of stored inter-arrival times
    u64 sum = 0;
    u32 count = 0;
    
    #pragma unroll
    for (u32 i = 0; i < 8; i++) {
        if (inter_arrival_history[i] > 0) {
            sum += inter_arrival_history[i];
            count++;
        }
    }
    
    if (count == 0)
        return BURST_THRESHOLD_NS;  // fallback to fixed threshold
    
    u64 avg_inter_arrival = sum / count;
    
    // Burst threshold = 1.5x average inter-arrival time
    // (packets arriving faster than 1.5x average are considered bursts)
    u64 threshold = (avg_inter_arrival * 3) / 2;
    
    // Bound the threshold: min 3ms, max 8ms
    if (threshold < 3000000ULL)
        threshold = 3000000ULL;
    if (threshold > 8000000ULL)
        threshold = 8000000ULL;
    
    return threshold;
}

// -- Helper: Detect burst mode with adaptive threshold --
static __always_inline bool is_burst(u64 now) {
    if (net_prev_packet_ts == 0)
        return false;
    
    u64 inter_arrival_ns = (now > net_prev_packet_ts) ?
        (now - net_prev_packet_ts) : 0;
    
    // Update history for future adaptive threshold calculations
    if (inter_arrival_ns > 0) {
        update_inter_arrival_history(inter_arrival_ns);
    }
    
    u64 adaptive_threshold = get_adaptive_burst_threshold();
    return (inter_arrival_ns < adaptive_threshold);
}
