<DESCRIPTION>
The current program uses a binary threshold for regularity detection (variance < 50ms = bonus of 2000). However, analysis of prior programs shows that continuous variance-weighted regularity scoring performs better, particularly for LevelDB's highly predictable sequential index scans.

This change replaces the binary variance check with a continuous scoring function that rewards folios with lower variance more aggressively. The scoring uses safe arithmetic (multiplication and bit shifts) to avoid BPF verifier issues with division:
- For hot folios (interval_ewma < 100ms), calculate regularity_diff = interval_ewma - variance
- Apply bonus only when variance < interval_ewma (indicating regularity)
- Use bit shift `(5000 * regularity_diff) >> 32` to scale the bonus proportionally

This approach recognizes that LevelDB's sequential scans have extremely low variance relative to their mean interval, and should be protected more strongly than irregular access patterns, even if both fall below the 50ms threshold.
</DESCRIPTION>
