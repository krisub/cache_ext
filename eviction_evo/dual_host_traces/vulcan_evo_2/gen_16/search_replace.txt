<DESCRIPTION>
Enable RTT variance (jitter) tracking via GF_MDEV_US EWMA listener and use it to dynamically extend recency protection windows under high-jitter network conditions. When jitter is high (>10000us), the working set becomes less predictable and cache misses are more expensive due to variable latency. This change:

1. Enables EWMA listener for GF_MDEV_US with alpha=150 to track RTT variance
2. Extends the primary recency protection window from 5 seconds to 7 seconds when high jitter is detected
3. Increases the secondary recency bonus (<30s) from +1000 to +1200 under high jitter conditions

This recognizes that high-jitter networks have less predictable access patterns, and the working set may expand beyond the current 5-second window as applications adapt to variable latency. The pattern builds on previous success with multi-timescale EWMA tuning and adaptive protection strategies.
</DESCRIPTION>

    // Recency: protect recently accessed folios (likely in working set)
    // During congestion (packet loss), increase bonuses to be more conservative
    // and extend protection window to capture working set during sustained stress
    // High jitter (RTT variance) also extends working set window due to unpredictable latency
    u64 now = bpf_ktime_get_ns();
    s64 age = (s64)(now - meta->last_access_ts);
    s64 mdev_ewma = vulcan_get_ewma(GF_MDEV_US);
    bool high_jitter = (mdev_ewma > 10000);  // > 10ms jitter = high variance

    // Primary recency tier: extend from 5s to 7s under high jitter
    s64 primary_threshold = high_jitter ? 7000000000 : 5000000000;
    if (age < primary_threshold) {
        if (lost_max > 0) {
            score += 4500;  // 50% bonus during congestion
        } else {
            score += 3000;
