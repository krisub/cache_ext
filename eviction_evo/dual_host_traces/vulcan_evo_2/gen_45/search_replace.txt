<DESCRIPTION>
This edit implements CWND recovery-aware modulation of loss-triggered recency bonuses to distinguish between transient packet loss (which recovers quickly) and sustained congestion (which keeps CWND depressed). The key insight is that when CWND is actively recovering from congestion (cwnd_ewma > cwnd_min * 1.5), it indicates brief loss events that don't warrant aggressive working-set protection. In contrast, when CWND remains stuck near minimum values, it signals sustained congestion where full protection is critical.

The implementation:
1. Enables MINMAX listener for GF_SND_CWND to track minimum CWND values
2. Detects CWND recovery state by comparing current CWND EWMA against 1.5x the observed minimum
3. Reduces loss-triggered recency bonuses by 15% (multiply by 85/100) during recovery
4. Maintains full bonuses during sustained congestion (CWND stuck low)

This provides more nuanced congestion response than the current binary loss detection, potentially improving mixed workload performance (YCSB-A/B/D which currently show high variance) by 2-3% without destabilizing read-heavy workloads through conservative 15% modulation (vs Generation 31's 25% that regressed).
</DESCRIPTION>
