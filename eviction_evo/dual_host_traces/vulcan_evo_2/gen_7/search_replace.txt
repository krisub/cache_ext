congestion_aware_recency_decay
</NAME>

<DESCRIPTION>
The current program uses static recency bonuses (+3000 for <5s, +1000 for <30s). This change implements congestion-aware recency decay by modulating these bonuses based on packet loss detection. When `vulcan_get_max(GF_LOST) > 0` indicates network congestion, the recency bonuses are increased by 50% (+4500 and +1500 respectively). This makes the eviction policy more conservative during network stress, protecting recently accessed folios more aggressively when cache misses are most expensive. The `lost_max` value is already computed earlier in the function, so this change reuses it to conditionally adjust recency protection without additional overhead.
</DESCRIPTION>
