dual_metric_sustained_congestion_detection
</NAME>

<DESCRIPTION>
This change implements dual-metric sustained congestion detection by combining loss persistence with CWND collapse ratio. The current policy already detects congestion using CWND vs SSTHRESH comparison, but this adds a complementary signal that identifies when CWND has collapsed below its historical minimum during packet loss - a strong indicator of sustained network stress.

The key improvements are:
1. Enable MINMAX listener for GF_SND_CWND to track historical min/max values (currently only EWMA is enabled)
2. Detect sustained CWND collapse: when CWND_EWMA < CWND_MIN * 1.3 AND loss is present
3. Stack an additional +1000 bonus (in primary tier), +1000 (in secondary tier), and +500 (in tertiary tier) with existing congestion bonuses rather than replacing them

This provides more reliable working-set expansion during genuine sustained congestion while avoiding false positives from transient conditions. The conservative 1.3x ratio threshold ensures we only trigger on true CWND collapse, not normal fluctuations.
</DESCRIPTION>
