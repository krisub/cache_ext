<DESCRIPTION>
This edit implements the recommended per-folio access regularity scoring with variance-weighted bonuses. The current code uses a binary variance check (< 50ms = regular, gets +2000 bonus). This change replaces it with a continuous scoring function that computes regularity as `1.0 - min(1.0, variance / interval_ewma)` (using integer arithmetic scaled by 1000 to avoid floating point). The bonus is then `5000 * regularity`, which rewards predictable access patterns proportionally rather than binary. For example, a folio with 10% variance relative to mean interval gets a 4500 bonus, while 50% variance gets 2500, and 100% variance gets 0. This better captures the spectrum of access regularity and should improve cache-friendliness detection across mixed workloads.

Additionally, I'm enabling GF_MDEV_US (jitter) tracking which was present in the best-performing program but missing in the current one, and adding jitter-aware logic to extend protection windows during high network variance conditions.
</DESCRIPTION>

    s64 interval_max = meta->interval_minmax.max_val;
    if (interval_min > 0 && interval_max > 0 && interval_ewma > 0) {

        // regularity_scaled = 1000 - min(1000, (variance * 1000) / interval_ewma)
