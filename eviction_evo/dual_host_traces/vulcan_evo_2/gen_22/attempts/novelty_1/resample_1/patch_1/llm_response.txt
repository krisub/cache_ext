<DESCRIPTION>
The current implementation uses a binary threshold for regularity detection: if variance < 50ms, add a fixed 2000 point bonus. This is too simplistic and doesn't distinguish between moderately regular and highly regular access patterns.

This change implements continuous variance-weighted regularity scoring that rewards predictable access patterns proportionally to their regularity. The regularity score is computed as: `regularity = max(0, 1 - variance/interval_ewma)`, which captures how stable the access pattern is relative to its mean interval.

The benefits:
1. **Proportional rewards**: Folios with very low variance relative to their mean interval get higher bonuses than those with moderate variance
2. **Context-aware**: The same absolute variance is treated differently for fast vs slow access patterns (e.g., 10ms variance on a 20ms interval is worse than 10ms variance on a 100ms interval)
3. **Hot folio emphasis**: We apply stronger regularity bonuses (up to 5000 points) for hot folios (< 100ms interval) since these are most likely to be working set pages that benefit from predictable access

This replaces the binary 50ms threshold with a continuous scoring function that better captures the spectrum of access pattern regularity, which should improve cache retention decisions for frequently-accessed, predictably-accessed pages across the diverse workload mix.
</DESCRIPTION>
