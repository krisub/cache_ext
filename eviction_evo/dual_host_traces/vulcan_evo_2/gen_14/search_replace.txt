cwnd_ssthresh_congestion_phase_detection
</NAME>

<DESCRIPTION>
Add CWND-to-SSTHRESH ratio monitoring to detect congestion phase more precisely. The slow-start threshold (ssthresh) marks the boundary between slow-start and congestion avoidance phases. When CWND drops below ssthresh (typically after packet loss/timeout), the connection enters congestion avoidance where throughput is limited.

By enabling MINMAX listener for GF_SND_SSTHRESH and comparing cwnd_ewma to ssthresh_min, we can detect when the connection is stuck in congestion avoidance (cwnd_ewma < ssthresh_min * 1.5). This captures sustained congestion better than just loss detection, which only catches transient events.

During congestion avoidance phase, cache misses are extremely expensive because the connection's throughput is already constrained. We add a +1500 protective bonus to prioritize keeping the working set in cache and avoid additional latency from evictions.

This approach is more precise than Generation 9's cwnd_min < 10 heuristic because it uses the relative comparison against ssthresh, which adapts to different network conditions and connection states.
</DESCRIPTION>
