cwnd_aware_loss_amplification
</NAME>

<DESCRIPTION>
Implement CWND-aware loss amplification with sustained congestion detection. The current policy applies fixed loss-triggered bonuses (+4500/+1500/+500) whenever packet loss is detected. However, this doesn't distinguish between brief transient loss (where CWND recovers quickly) and sustained congestion (where CWND remains depressed).

By tracking CWND minimum via MINMAX listener and checking if `vulcan_get_ewma(GF_SND_CWND)` is below `vulcan_get_min(GF_SND_CWND) * 1.3`, we can detect when the system is in a sustained congestion state rather than recovering from a transient loss event. During sustained congestion, each cache miss is even more expensive because the network path is severely constrained, so working-set protection should be amplified.

When sustained congestion is detected (cwnd_ewma < cwnd_min * 1.3), we increase the loss-triggered recency bonuses by 30% (e.g., +4500 becomes +5850, +1500 becomes +1950, +500 becomes +650). This provides more aggressive working-set protection during periods of sustained network degradation, which should improve performance on mixed workloads where congestion patterns vary (YCSB-A/B/D combinations currently showing 4,049-5,373 ops/sec).
</DESCRIPTION>
