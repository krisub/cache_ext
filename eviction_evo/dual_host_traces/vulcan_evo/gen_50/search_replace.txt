<DESCRIPTION>
The current program uses MINMAX listener for packet loss (GF_LOST), which causes the max_lost value to persist indefinitely once loss is observed, leading to sustained over-protection. The best-performing prior program (2184.76 combined score) used a RollingWindow listener instead, providing natural time-decay as old loss events age out of the window.

This change implements time-decayed loss protection by:
1. Switching GF_LOST from MINMAX to RollingWindow (size 5) to provide automatic aging
2. Implementing graduated loss protection that checks multiple positions in the rolling window:
   - Latest loss (position 0): 15% boost (full protection)
   - Recent loss (position 1): 8% boost (moderate protection)
   - Older loss (position 2): 3% boost (minimal protection)
   - Loss events >2 positions old: no boost (aged out)

This provides responsive protection during active congestion while preventing stale loss signals from causing sustained over-protection. The rolling window naturally implements time-decay without requiring explicit per-folio timestamp tracking, matching the approach that achieved the highest combined score in prior generations.
</DESCRIPTION>
