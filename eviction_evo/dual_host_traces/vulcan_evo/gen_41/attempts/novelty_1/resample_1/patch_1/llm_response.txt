<DESCRIPTION>
This edit addresses the recommendation to add time-decay to loss protection while improving recency handling based on the best-performing prior program. The changes include:

1. **Time-decayed loss protection**: Switch GF_LOST from MINMAX to RollingWindow (size 5) to naturally age out stale loss signals. Implement graduated decay: recent loss (latest sample) gets full 15% boost, older loss (1-2 samples back) gets reduced boost (8% and 3%), and no recent loss gets no boost. This prevents sustained over-protection from stale loss signals while maintaining responsiveness to active congestion.

2. **Recency-weighted base score**: Move recency weighting into the base_score calculation itself (as in the 2184.76 program) rather than as a separate additive bonus. This gives 50% boost for accesses <1s old, decaying linearly to 0% at 10s, making temporal locality a first-class component of the score.

3. **Simplified RTT logic**: Return to absolute RTT thresholds (5ms, 10ms) instead of trend detection, which proved simpler and more effective in the best-performing program.

These changes directly implement the recommendation's guidance about decay while incorporating proven patterns from the highest-scoring prior program.
</DESCRIPTION>
