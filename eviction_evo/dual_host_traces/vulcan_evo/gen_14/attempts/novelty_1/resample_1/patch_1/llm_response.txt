<DESCRIPTION>
The current program has lost performance by reverting to pure LFU with no network listeners. Looking at the prior evolution, Program 5 (score 1977.84) achieved the best performance by enabling smart network-aware listeners and per-folio heat tracking. 

The recommendation is to implement **time-decay for loss-triggered protection** to prevent sustained over-protection after transient loss events. Currently, if max_lost > 0 is detected, a constant 30% boost is applied indefinitely until loss clears. This can lock the cache into overly conservative eviction during/after brief loss spikes.

The solution is to:
1. Re-enable the high-performing listener configuration from Program 5 (SRTT_US with EWMA+RW, PACKETS_OUT with EWMA, LOST with MINMAX, plus per-folio EWMA+MINMAX)
2. Add per-folio tracking of last_loss_event_ts to detect when loss was last observed relative to each folio
3. Implement exponential decay: when loss is old, the protection boost decays toward 0 (e.g., ~37% boost after 100ms, ~5% after 300ms)
4. Restore the sophisticated scoring function that combines recency, network conditions, and per-folio heat

This prevents the cache from over-protecting folios based on stale loss information while maintaining strong protection during active network degradation.
</DESCRIPTION>

    struct folio *folio = node->folio;
    if (!folio)

/*
 * Network-aware LFU with time-decayed loss protection.
 * Kernel picks LOWEST score in each batch. S64_MAX = never prefer as victim.
 * 
 * Loss detection applies adaptive protection boost that decays over time,
 * preventing sustained over-protection after transient loss events.
 * Combines RTT sensitivity, per-folio heat tracking, and recency.
 */
static s64 bpf_score_fn(struct cache_ext_list_node *node)
{
    struct folio *folio = node->folio;
    if (!folio)
        return S64_MAX;

    if (folio_test_dirty(folio) || folio_test_writeback(folio))
        return S64_MAX;
    if (!folio_test_uptodate(folio) || !folio_test_lru(folio))
        return S64_MAX;

    u64 key = (u64)folio;
    struct vulcan_folio_metadata *meta =
        bpf_map_lookup_elem(&folio_metadata_map, &key);
    if (!meta)
        return S64_MAX;

    s64 base_score = (s64)meta->access_count;

    /* Network-aware protection: boost when RTT is high (cache misses are expensive) */
    s64 srtt_ewma = vulcan_get_ewma(GF_SRTT_US);
    s64 network_factor = 100;  /* baseline: 1.0x in fixed-point (÷100) */

    /* Elevated RTT (>5ms smoothed): protect working set more aggressively */
    if (srtt_ewma > 5000) {
        network_factor = 125;  /* 1.25x protection */
    } else if (srtt_ewma > 10000) {
        network_factor = 150;  /* 1.5x protection for >10ms RTT */
    }

    /* Packet loss detected with time-decay: boost decays over time to prevent
     * sustained over-protection after transient loss events.
     * Decay formula: boost_factor = 100 + decay * 30, where decay declines
     * exponentially. After ~100ms, boost is ~37% (37 extra). After ~300ms, ~5%.
     */
    s64 max_lost = vulcan_get_max(GF_LOST);
    if (max_lost > 0) {
        u64 now = bpf_ktime_get_ns();
        u64 time_since_loss_ns = now - last_loss_event_ts;
        s64 loss_boost = 30;  /* 30% base boost when loss detected */
        
        /* Exponential decay: boost *= exp(-(time_since_loss / 100ms))
         * Use fixed-point approximation: decay ~= 1000 / (1000 + time_ms / 2)
         * for simplicity (avoids expensive exponential in BPF). */
        if (time_since_loss_ns > 1000000) {  /* > 1ms */
            u64 time_since_loss_ms = time_since_loss_ns / 1000000;
            u64 decay_denom = 1000 + (time_since_loss_ms >> 1);  /* /2 for aggressive decay */
            loss_boost = (loss_boost * 1000) / decay_denom;
        }
        
        network_factor = (network_factor * (100 + loss_boost)) / 100;
    }

    /* Apply network-aware protection factor */
    s64 score = (base_score * network_factor) / 100;

    /* Recency bonus: protect pages accessed in last 5 seconds */
    u64 now = bpf_ktime_get_ns();
    u64 time_since_access = now - meta->last_access_ts;
    if (time_since_access < 5000000000ULL) {  /* 5 seconds in ns */
        score += 50;
    }

    /* Per-folio heat: low interval EWMA = hot (frequently accessed) */
    s64 interval_ewma = meta->interval_ewma.value;
    if (interval_ewma > 0 && interval_ewma < 1000000000) {  /* < 1 second */
        /* Hot folio: very frequent accesses */
        score += 100;
    } else if (interval_ewma > 10000000000) {  /* > 10 seconds */
        /* Cold folio: infrequent accesses, prefer as victim */
        if (score > 100) score -= 100;
    }

    /* LevelDB: protect index block (last page of file) */
    if (is_last_page_in_file(folio))
        score += 100000;

    return score;
}
