<DESCRIPTION>
The current program is a pure LFU baseline that lacks network awareness and recency weighting, resulting in significantly lower performance (1965.52) compared to the best prior generation (2090.49). 

The recommendation is to implement **recency-weighted access rate normalization** combined with **network-adaptive protection**. This approach addresses two key deficiencies:

1. **Raw access count doesn't distinguish temporal locality**: A folio accessed once per second is more valuable than one accessed frequently but not recently. By weighting access_count by recency, we preserve high scores for actively-used pages while allowing cold, infrequently-accessed pages to become eviction candidates.

2. **Network conditions demand adaptive protection**: When RTT is elevated or loss is detected, each cache miss becomes expensive. Under congestion, we should protect the working set more aggressively. Under good network conditions, we can afford to evict colder pages.

The implementation uses:
- **Recency decay**: `base_score = access_count * (100 - recency_decay) / 100` where recency_decay declines linearly from 80 when accessed within 1 second to 0 after 10 seconds. This gives recently-accessed frequent pages ~1.8x boost while cold frequent pages get minimal boost.
- **RTT-sensitive protection factors**: When smoothed RTT > 10ms, apply 1.5x protection; >5ms applies 1.25x. This prevents thrashing under latency.
- **Network loss detection**: Modest 15% boost when loss is detected AND RTT is elevated (>3ms), preventing stale loss signals from causing sustained over-protection.
- **Per-folio heat tracking**: Use interval_ewma (exponential moving average of inter-access intervals) to distinguish hot (frequently-accessed) from cold folios, independent of historical access count.

This combines the proven network-aware techniques from Gen 14 (2090.49) with the recency weighting recommendation, targeting the sweet spot between frequency, recency, and network conditions.

static s64 bpf_score_fn(struct cache_ext_list_node *node)
{
    struct folio *folio = node->folio;
    if (!folio)
        return S64_MAX;

    if (folio_test_dirty(folio) || folio_test_writeback(folio))
        return S64_MAX;
    if (!folio_test_uptodate(folio) || !folio_test_lru(folio))
        return S64_MAX;

        bpf_map_lookup_elem(&folio_metadata_map, &key);

    if (is_last_page_in_file(folio))

/*
 * Recency-weighted LFU with network-adaptive protection.
 * Kernel picks LOWEST score in each batch. S64_MAX = never prefer as victim.
 *
 * Key innovation: base_score combines access frequency with recency weighting
 * to distinguish recently-active frequent pages from cold, infrequently-accessed
 * pages. Network conditions (RTT, loss) trigger adaptive protection to prevent
 * thrashing during congestion.
 */
static s64 bpf_score_fn(struct cache_ext_list_node *node)
{
    struct folio *folio = node->folio;
    if (!folio)
        return S64_MAX;

    if (folio_test_dirty(folio) || folio_test_writeback(folio))
        return S64_MAX;
    if (!folio_test_uptodate(folio) || !folio_test_lru(folio))
        return S64_MAX;

    u64 key = (u64)folio;
    struct vulcan_folio_metadata *meta =
        bpf_map_lookup_elem(&folio_metadata_map, &key);
    if (!meta)
        return S64_MAX;

    /* Recency-weighted access count: boost recently-accessed pages.
     * Linear decay from 80% boost (< 1 second) to 0% boost (10+ seconds).
     * Formula: recency_boost = 80 * max(0, 1 - time_since_access / 10s)
     * Applied as: base_score = access_count * (100 + recency_boost) / 100 */
    u64 now = bpf_ktime_get_ns();
    u64 time_since_access = now - meta->last_access_ts;
    s64 recency_boost = 0;

    if (time_since_access < 10000000000ULL) {  /* Within 10 seconds */
        s64 elapsed_deciseconds = time_since_access / 1000000000ULL;  /* Convert ns to deciseconds (0.1s units) */
        recency_boost = 80 - (elapsed_deciseconds * 8);  /* Linear decay: 80 at 0s, 0 at 10s */
        if (recency_boost < 0) recency_boost = 0;
    }

    s64 base_score = ((s64)meta->access_count * (100 + recency_boost)) / 100;

    /* Network-aware protection: when RTT is high, cache misses are expensive */
    s64 srtt_ewma = vulcan_get_ewma(GF_SRTT_US);
    s64 network_factor = 100;  /* baseline: 1.0x in fixed-point (÷100) */

    /* Elevated RTT: protect working set more aggressively */
    if (srtt_ewma > 10000) {  /* >10ms smoothed RTT */
        network_factor = 150;  /* 1.5x protection */
    } else if (srtt_ewma > 5000) {  /* >5ms smoothed RTT */
        network_factor = 125;  /* 1.25x protection */
    }

    /* Packet loss detected: be more conservative */
    s64 max_lost = vulcan_get_max(GF_LOST);
    if (max_lost > 0 && srtt_ewma > 3000) {  /* Loss + RTT > 3ms */
        network_factor = (network_factor * 115) / 100;  /* additional 15% boost */
    }

    /* Apply network-aware protection factor */
    s64 score = (base_score * network_factor) / 100;

    /* Per-folio heat: use interval EWMA to distinguish hot vs cold folios.
     * Low interval_ewma = frequent accesses (hot).
     * High interval_ewma = infrequent accesses (cold). */
    s64 interval_ewma = meta->interval_ewma.value;
    if (interval_ewma > 0 && interval_ewma < 1000000000) {  /* < 1 second */
        /* Hot folio: very frequent accesses, protect strongly */
        score += 100;
    } else if (interval_ewma > 10000000000) {  /* > 10 seconds */
        /* Cold folio: infrequent accesses, prefer as victim */
        if (score > 100) score -= 100;
    }

    /* LevelDB: protect index block (last page of file) */
    if (is_last_page_in_file(folio))
        score += 100000;

    return score;
}
