<DESCRIPTION>
This edit implements adaptive recency decay calibration based on per-folio access burstiness, extending the proven 50% boost within 1s pattern from Generation 39 (which scored 2184.76).

The key insight is that Generation 39's simpler linear decay (50% boost at 1s, decaying to 0% at 10s) outperforms the current multi-scale approach. However, we can improve upon Generation 39 by making the recency boost adaptive to individual folio characteristics.

We compute a burstiness metric from the already-enabled interval_minmax listener: `burstiness = max_interval / min_interval`. This quantifies how variable a folio's access pattern is:
- High burstiness (>10): Access pattern is bursty/irregular → Apply 70% recency boost to protect during active periods
- Normal burstiness (3-10): Regular access pattern → Apply 50% boost (proven effective in Gen 39)
- Low burstiness (<3): Very steady/predictable access → Apply 30% boost (less aggressive protection)

This adaptive approach should reduce throughput variance in dual_small_vs_large (current std: 161.38) by better distinguishing between the fast reader's bursty accesses and the slow writer's steady pattern, while maintaining the proven temporal protection strategy.
