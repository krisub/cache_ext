<DESCRIPTION>
The current program uses a simple flat recency bonus (< 5s gets +50), which underperforms compared to Generation 39's proven multi-scale temporal protection. This edit implements adaptive recency decay calibration based on per-folio access burstiness, extending Generation 39's successful 50% boost within 1s pattern.

The key improvements:
1. Replace flat recency bonus with multi-scale temporal decay (< 1s: 50% boost, decaying linearly to 0% at 10s)
2. Compute per-folio burstiness from interval_minmax listeners (already enabled): burstiness = max_interval / min_interval
3. Adaptively scale recency boost based on burstiness:
   - Bursty folios (burstiness > 10): 70% boost - these have sporadic access patterns and need stronger protection during active periods
   - Normal folios (3 <= burstiness <= 10): 50% boost - standard working-set protection
   - Steady-access folios (burstiness < 3): 30% boost - regular access patterns need less aggressive protection

This directly addresses the recommendation to make decay rates responsive to individual folio access patterns, which should reduce dual_small_vs_large throughput variance (currently std: 105.38) by better handling heterogeneous workloads.
