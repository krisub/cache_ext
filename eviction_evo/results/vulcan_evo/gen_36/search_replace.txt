<DESCRIPTION>
This edit implements a graduated three-tier jitter-aware recency threshold scaling system based on RTT variance (jitter). The approach extends the successful jitter-aware strategy from program 5 (which achieved score 5667.51) but uses three graduated tiers instead of a binary threshold.

The reasoning is that network jitter (RTT mean deviation) indicates unpredictable latency patterns. During high jitter periods, the working set becomes less predictable and may expand, requiring broader temporal protection windows. The graduated approach captures this more accurately than binary thresholds:

- Very high jitter (>15ms, mdev_ewma > 15000): Extends primary recency window to 8 seconds and increases secondary bonus to +1300. This captures an expanded working set during severe network unpredictability.
- High jitter (>10ms, mdev_ewma > 10000): Uses 7s primary window and +1200 bonus, matching the proven approach from program 5.
- Normal latency (≤10ms): Uses baseline 5s primary window and +1000 bonus.

This graduated scaling provides smooth adaptation to varying network conditions without introducing complex calculations that could trigger BPF verifier issues. The conservative bonus amplification (300 point increments) prevents over-protection while still capturing the expanded working set during severe jitter.
