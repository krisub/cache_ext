<DESCRIPTION>
The current program regressed from 4743.22 to 4566.55 by using only cwnd_min < 10 for severe collapse detection. This is too coarse-grained and misses moderate congestion phases.

Adding CWND-to-SSTHRESH ratio monitoring provides a more nuanced congestion signal:
- When `cwnd_ewma < ssthresh_min * 1.5`, the TCP connection is in congestion avoidance or recovery phase
- This catches moderate congestion earlier than the severe collapse threshold
- The ratio comparison distinguishes between transient CWND drops (which recover quickly back above SSTHRESH) and sustained congestion (where CWND stays suppressed below SSTHRESH)

Implementation:
1. Enable MINMAX listener for GF_SND_SSTHRESH to track minimum slow-start threshold
2. Add congestion phase detection using `vulcan_get_ewma(GF_SND_CWND)` vs `vulcan_get_min(GF_SND_SSTHRESH)`
3. Apply +1500 bonus when in congestion phase (less aggressive than the +2000 for severe collapse, since these conditions can coexist)

This provides layered congestion detection:
- Normal loss (lost_max > 0): +33% of access_count
- Congestion phase (cwnd < ssthresh * 1.5): +1500
- Severe collapse (cwnd_min < 10): +2000
</DESCRIPTION>
