<DESCRIPTION>
The current code uses a binary threshold for regularity detection (variance < 50ms → +2000 bonus). This doesn't distinguish between very regular patterns (variance = 1ms) and moderately regular patterns (variance = 49ms).

I'm implementing continuous variance-weighted regularity scoring that rewards highly predictable access patterns more aggressively. For hot folios (interval_ewma < 100ms), we calculate a scaled bonus based on how much smaller the variance is compared to the mean interval: `regularity_bonus = (5000 * (interval_ewma - variance)) >> 32`.

This uses safe arithmetic (multiplication and bit shifts) to avoid division, which is important for BPF verifier compliance. The formula rewards extremely low-variance patterns (like LevelDB's sequential index scans) more than irregular patterns, providing a continuous gradient rather than a binary decision.

Additionally, I'm removing the "Dual-metric congestion detection" that was added in the current program, as it appears to have degraded performance compared to the simpler approach in the best-performing programs.
</DESCRIPTION>
