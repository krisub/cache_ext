<DESCRIPTION>
This edit implements three-tier jitter-aware recency threshold scaling with graduated window extension. The current program lacks jitter awareness (GF_MDEV_US is disabled), while the best-performing prior program (5667.51) showed a +2.5% gain using two-tier jitter thresholds.

This enhancement adds a third tier to better handle severe network unpredictability:
- Very high jitter (>15ms): Extends primary window to 9s and secondary bonus to +1400
- High jitter (>10ms): Extends primary window to 7s and secondary bonus to +1200
- Normal jitter (≤10ms): Uses baseline 5s primary window and +1000 secondary bonus

The rationale is that during severe network unpredictability, working sets expand as the system compensates for increased latency variance. Graduated thresholds capture this more effectively than binary switches, potentially adding 1-2% improvement over the current configuration by protecting the expanded working set during sustained jitter while maintaining conservative protection during normal latency conditions.
</DESCRIPTION>
