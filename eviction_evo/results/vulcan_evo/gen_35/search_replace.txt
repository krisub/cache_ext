<DESCRIPTION>
The current program regressed from Generation 5's score of 5667.51 to 5386.91. The recommendation suggests implementing dual-metric congestion detection that combines loss persistence with CWND collapse ratio to more reliably identify sustained congestion versus transient congestion spikes.

The key insight is that transient congestion causes temporary CWND drops that recover quickly, while sustained congestion keeps CWND depressed below its historical minimum. By requiring BOTH persistent losses (lost_max > 0) AND CWND significantly below its historical minimum (< 1.3x), we can provide an additional protective signal that stacks with existing loss-triggered bonuses.

This approach:
1. Re-enables MINMAX listener on GF_SND_CWND to track historical minimum
2. Detects sustained congestion when CWND_EWMA < CWND_MIN * 1.3 AND losses persist
3. Applies an additional +1500 bonus (conservative, additive stacking)
4. Uses a conservative 1.3x ratio threshold to avoid false positives

This complements the existing congestion detection by adding a duration-aware signal that protects the working set more aggressively during prolonged network degradation.
