loss_decay_adaptive_protection
</NAME>

<DESCRIPTION>
The current loss-based protection applies a uniform 15% boost whenever packet loss is detected (via MaxMin listener on GF_LOST), but the loss counter in kernel TCP state can persist long after network conditions improve, causing sustained over-protection that hurts throughput especially under high-frequency workloads (dual_small_vs_large).

The proposed change implements time-decay for the loss boost:
1. Track a global timestamp when packet loss was most recently detected
2. In the scoring function, calculate elapsed time since last loss event
3. Decay the 15% boost gradually over 150ms (full boost for 0-50ms, then linear decay to negligible by 150ms)
4. This maintains responsiveness to transient congestion while preventing stale loss signals from locking the cache into overly conservative eviction

This addresses the observation that the dual_congested trace (where loss is more persistent) performs better than dual_small_vs_large (where loss is transient). By allowing the boost to naturally decay, we can improve small_vs_large performance without sacrificing congested-scenario protection.

The implementation uses a simple BPF map to store the last loss event timestamp and applies integer arithmetic for the decay calculation, remaining fully BPF-compatible.
</DESCRIPTION>

        /* Read back the timestamp (should be the one we just wrote) */
        u64 *last_loss_ts_ptr = bpf_map_lookup_elem(&loss_event_ts_map, &loss_key);
        if (last_loss_ts_ptr) {
            u64 elapsed_ns = now_ns - *last_loss_ts_ptr;
            u64 elapsed_ms = elapsed_ns / 1000000;  /* Convert to milliseconds */

            /* Decay formula: full 15% boost for <= 50ms, linear decay to negligible by 150ms
             * boost_factor = 115 - (elapsed_ms - 50) * 10 / 100, clamped to [100, 115]
             * For elapsed_ms <= 50: boost_factor = 115
             * For elapsed_ms == 150: boost_factor = 115 - 100*10/100 = 100 (no boost)
             */

                loss_boost_factor = 115;  /* Full boost for recent loss */
            } else if (elapsed_ms >= 150) {
                loss_boost_factor = 100;  /* No boost for stale loss (>150ms) */
            } else {
                /* Linear decay from 115 to 100 over 50-150ms interval */
                s64 decay_region = elapsed_ms - 50;  /* 0 to 100 */
                loss_boost_factor = 115 - (decay_region / 10);  /* Decays by 1 per 10ms */
            }
        }
