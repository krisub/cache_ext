dual_metric_congestion_detection
</NAME>

<DESCRIPTION>
Implement dual-metric congestion detection that combines loss persistence with CWND collapse ratio for more reliable sustained congestion identification. This enhancement distinguishes between transient congestion (CWND temporarily low but recovering quickly) and sustained congestion (CWND stuck below historical minimum while losses persist).

The approach:
1. Enable both MINMAX and EWMA listeners for GF_SND_CWND to track historical minimum
2. Add a secondary congestion signal: when EWMA(CWND) < MIN(CWND) * 1.3 AND packet loss detected, add +1500 bonus
3. Use conservative 1.3x ratio (vs 1.4x that regressed in generation 28) 
4. Stack this bonus additively with existing loss-triggered bonuses instead of replacing them

This provides a more reliable congestion signal than using loss or CWND alone, as it requires both persistent loss AND CWND being stuck below historical levels, avoiding false positives from transient network events while capturing true sustained congestion periods that require aggressive working set protection.
</DESCRIPTION>
