continuous_variance_weighted_regularity_bonus

<DESCRIPTION>
The current binary variance check (`if (variance < 50000000)`) provides a flat 2000 bonus for any folio with low variance, regardless of how regular the pattern is. This misses the opportunity to distinguish between "very regular" (variance = 5ms) and "somewhat regular" (variance = 45ms) access patterns, particularly for hot folios.

For hot folios (interval_ewma < 100ms), LevelDB's sequential index scans exhibit extremely low variance (often < 10ms) and deserve stronger protection. We implement a continuous scoring function that scales the bonus proportionally to regularity:

- regularity = (interval_ewma - variance) / interval_ewma (when variance < interval_ewma)
- bonus = (5000 * regularity) for hot folios

This is implemented in integer arithmetic as: `bonus = (5000 * (interval_ewma - variance)) / interval_ewma`

For non-hot folios, we retain the existing binary check to avoid penalizing legitimate warm access patterns that may have higher absolute variance due to longer intervals.

This change should improve YCSB-C and YCSB-E performance (the read-heavy workloads that benefit most from protecting sequential scan patterns) by 2-3%, potentially pushing combined score above 5700.
</DESCRIPTION>
