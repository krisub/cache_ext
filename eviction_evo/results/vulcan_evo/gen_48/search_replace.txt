<DESCRIPTION>
The current program uses a simple fixed recency bonus (+50 points if accessed within 5 seconds), which doesn't distinguish between different folio access patterns. Generation 39's fine-grained recency weighting (50% boost within 1s, decaying to 0% at 10s) achieved the best combined score (2184.76) by making recency a first-class component of the scoring function.

This edit extends that proven approach by implementing adaptive per-folio recency decay calibration. Instead of applying the same decay curve to all folios, we compute a "burstiness" metric from the per-folio interval_minmax listeners (max_val / min_val ratio) to characterize each folio's access pattern:
- High burstiness (ratio > 10): folios accessed in bursts with long gaps between → apply stronger recency boost (70%) to catch working-set transitions
- Low burstiness (ratio < 3): folios with steady, predictable access → apply moderate recency boost (30%) to avoid over-protecting
- Medium burstiness: interpolated boost (30-70%)

The recency weighting uses a smooth decay curve similar to Gen 39 but scaled by per-folio burstiness:
- Base formula: recency_factor = burstiness_adjusted_boost * (1 - time_since_access / 10s)
- Applied as: base_score * (100 + recency_factor) / 100

This should improve dual_small_vs_large throughput (currently 1601.83 mean with std 138.46) by better adapting to the mixed access patterns (fast reader with small values vs slow writer with large values), while maintaining strong dual_congested performance through the existing network-aware protection.
</DESCRIPTION>
