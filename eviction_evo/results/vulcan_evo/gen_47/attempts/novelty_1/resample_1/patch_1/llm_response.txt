<DESCRIPTION>
The recommendation suggests adding a more reliable sustained congestion detection mechanism by combining loss persistence with CWND collapse ratio. The current code compares CWND to SSTHRESH, but a more reliable signal is to compare current CWND EWMA against historical minimum CWND. This detects when CWND is stuck below its baseline (sustained congestion) rather than just temporarily low.

Key improvements:
1. Enable MINMAX listener for GF_SND_CWND (in addition to existing EWMA) to track historical CWND range
2. Add new detection: when `vulcan_get_ewma(GF_SND_CWND) < vulcan_get_min(GF_SND_CWND) * 1.3` AND losses are present
3. Apply +1000 bonus that stacks with existing loss bonuses (not replacing them)
4. Use conservative 1.3x ratio threshold (more conservative than 1.4x or 1.5x)

This provides a more reliable congestion signal than CWND vs SSTHRESH because it identifies when CWND has collapsed below its historical norm and stays there, which is a strong indicator of sustained network stress requiring aggressive working-set protection.
