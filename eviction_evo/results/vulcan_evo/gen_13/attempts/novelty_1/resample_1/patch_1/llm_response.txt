tune_ewma_alpha_per_feature_timescale
</NAME>

<DESCRIPTION>
Optimize EWMA alpha parameters based on network timescale analysis. The current configuration uses alpha=200 for SRTT, alpha=150 for CWND, and alpha=100 for inter-arrival. However, these features operate on different timescales:

1. **SRTT (Smoothed RTT)**: RTT fluctuations occur on sub-second timescales during congestion events. Since each cache miss is expensive under high RTT, the eviction policy needs to react quickly to RTT spikes. Increasing alpha from 200 to 275 makes the EWMA more responsive to sudden RTT changes, allowing faster adaptation to network degradation.

2. **INTER_ARRIVAL**: Packet inter-arrival times are more stable over longer periods and exhibit more noise from transient variations. A lower alpha (60 instead of 100) provides better smoothing, filtering out short-term jitter while preserving the underlying packet arrival pattern. This prevents over-reaction to temporary burst behavior.

3. **CWND**: Congestion window changes moderately fast during congestion control state transitions. A slight increase from 150 to 175 improves responsiveness to congestion window dynamics without introducing excessive noise.

This tuning aligns the smoothing behavior with the actual timescales of network phenomena, potentially capturing better performance than the fixed alpha values used in previous generations.
</DESCRIPTION>
