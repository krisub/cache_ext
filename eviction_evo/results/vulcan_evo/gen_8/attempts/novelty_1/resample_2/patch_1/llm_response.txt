<DESCRIPTION>
The current program uses per-folio interval EWMA to detect hot folios (low average inter-access time = frequently accessed). However, it doesn't distinguish between folios with regular, predictable access patterns vs. sporadic access patterns with the same average.

This edit extends the per-folio heat detection by:
1. Enabling the MINMAX listener in folio_cfg (alongside existing EWMA) to track min/max inter-access intervals
2. Computing variance as `max_val - min_val` to measure temporal regularity
3. Applying an additional +2000 bonus to folios with low variance (<50ms spread), indicating predictable, periodic access patterns

This helps retain working set pages that are accessed regularly (e.g., hot keys in YCSB workloads, index blocks accessed periodically), improving cache hit rates for workloads with temporal locality and regular access patterns. The variance metric complements the existing interval EWMA by capturing access pattern consistency, not just frequency.
</DESCRIPTION>
