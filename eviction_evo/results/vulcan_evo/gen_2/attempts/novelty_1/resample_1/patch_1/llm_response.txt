# Analysis and Proposed Improvement

## Current State
The baseline policy is pure LFU (scoring by `access_count`) with no network awareness. Performance:
- **dual_small_vs_large**: 1373.23 ops/sec (fast zipfian reader + slow writer)
- **dual_congested**: 3456.26 ops/sec (both clients network-delayed)
- **Combined score**: 1965.52

## Key Observations

1. **LFU alone is insufficient**: Access count doesn't distinguish between:
   - Recently-active folios (should protect)
   - Stale folios that were accessed long ago (should evict)

2. **Burst patterns ignored**: The `dual_small_vs_large` workload has a zipfian reader that creates bursty request patterns. During bursts, protecting the working set is critical.

3. **Network metrics available but unused**: We have `GF_INTER_ARRIVAL` which can detect bursty traffic patterns.

4. **Per-folio recency not tracked**: The per-folio metadata can store `interval_ewma` (exponential moving average of inter-access times), which directly identifies hot vs. cold folios.

## Proposed Strategy

**Combine frequency + recency + burst awareness:**
- Enable `GF_INTER_ARRIVAL` (EWMA + RollingWindow) to detect burst patterns
- Enable per-folio `interval_ewma` to track access recency
- Enhance scoring function to:
  - Base score on `access_count` (frequency)
  - Penalize high `interval_ewma` (stale folios—easy evicts)
  - Boost score during detected bursts (protect working set when latency matters)
  - Keep LevelDB index block protection

This targets both workloads:
- **dual_small_vs_large**: Burst detection protects the reader's hot set; interval tracking evicts cold writer pages
- **dual_congested**: Recency tracking ensures we keep recently-active folios in limited cache

/*
 * Baseline: pure LFU (mimics cache_ext_sampling.bpf.c bpf_lfu_score_fn).
 * Kernel picks LOWEST score in each batch. S64_MAX = never prefer as victim.
 * Evolution can add vulcan_get_* calls and protection rules.
 */
static s64 bpf_score_fn(struct cache_ext_list_node *node)
{
    struct folio *folio = node->folio;
    if (!folio)
        return S64_MAX;

    if (folio_test_dirty(folio) || folio_test_writeback(folio))
        return S64_MAX;
    if (!folio_test_uptodate(folio) || !folio_test_lru(folio))
        return S64_MAX;

    u64 key = (u64)folio;
    struct vulcan_folio_metadata *meta =
        bpf_map_lookup_elem(&folio_metadata_map, &key);
    if (!meta)
        return S64_MAX;

    s64 score = (s64)meta->access_count;

    /* LevelDB: protect index block (last page of file) */
    if (is_last_page_in_file(folio))
        score += 100000;

    return score;
}

/*
 * Enhanced LFU with recency + burst awareness.
 * Kernel picks LOWEST score in each batch. S64_MAX = never prefer as victim.
 * Combines access_count (frequency) with interval_ewma (recency) and
 * burst detection to make smarter eviction decisions.
 */
static s64 bpf_score_fn(struct cache_ext_list_node *node)
{
    struct folio *folio = node->folio;
    if (!folio)
        return S64_MAX;

    if (folio_test_dirty(folio) || folio_test_writeback(folio))
        return S64_MAX;
    if (!folio_test_uptodate(folio) || !folio_test_lru(folio))
        return S64_MAX;

    u64 key = (u64)folio;
    struct vulcan_folio_metadata *meta =
        bpf_map_lookup_elem(&folio_metadata_map, &key);
    if (!meta)
        return S64_MAX;

    /* Base score: frequency (higher access_count = higher score = harder to evict) */
    s64 score = (s64)meta->access_count * 100;

    /* Recency penalty: folios with high interval_ewma (stale) get lower scores.
     * If a folio hasn't been accessed for a while (high interval_ewma),
     * make it easier to evict. Divide by large constant to normalize ns values. */
    if (meta->interval_ewma.value > 0) {
        score -= meta->interval_ewma.value / 100000;  // High interval → low score → evict first
    }

    /* Burst detection: if inter-arrival is low, we're in a bursty phase.
     * During bursts, protect the active working set by boosting scores. */
    s64 inter_arrival_ewma = vulcan_get_ewma(GF_INTER_ARRIVAL);
    if (inter_arrival_ewma > 0 && inter_arrival_ewma < 100000) {  // < 100us avg = burst
        score += 5000;  // Protect working set during burst
    }

    /* LevelDB: protect index block (last page of file) */
    if (is_last_page_in_file(folio))
        score += 100000;

    return score;
}
