<DESCRIPTION>
Looking at the performance progression, the best-performing program (5667.51) used MDEV-based jitter detection. The current program removed this and regressed slightly. However, rather than simply reverting, I'll implement the recommendation to replace the binary variance check with a continuous variance-weighted regularity scoring.

The current code uses a step function: if variance < 50ms, add 2000 points. This is too coarse and doesn't distinguish between highly regular patterns (variance ~0) and moderately regular patterns (variance ~45ms).

The new approach implements continuous regularity scoring using safe arithmetic (multiplication and right-shift) as recommended. For hot folios (interval_ewma < 100ms), we calculate:
`regularity_bonus = (5000 * (interval_ewma - variance)) >> 32`

This rewards highly predictable access patterns (low variance relative to mean interval) more aggressively than irregular patterns. This is particularly important for LevelDB's sequential index scans, which have extremely low variance and should receive stronger protection. The bit shift operation (>> 32) avoids division while providing appropriate scaling.
</DESCRIPTION>
