<DESCRIPTION>
The current program's time-decay loss mechanism added complexity without improving performance (1873.98 vs Generation 40's 2184.76). This edit implements the recommended adaptive recency decay calibration based on per-folio access burstiness to extend the proven 50% boost pattern from Generation 40.

The key insight is that folios with different access patterns should have different recency decay rates:
- **Bursty folios** (high variance in inter-access intervals, ratio > 10) get extended protection with 70% boost - these are working-set pages accessed in clusters
- **Normal folios** get the proven 50% boost from Generation 40
- **Steady-access folios** (low variance, ratio < 3) get faster decay with 30% boost - these are background/sequential pages

This approach:
1. Makes decay rates responsive to individual folio access patterns
2. Should reduce throughput variance in dual_small_vs_large (currently std: 168.85)
3. Extends the multi-scale temporal protection that worked well in Generation 40
4. Removes the problematic time-decay loss tracking that hurt performance
</DESCRIPTION>

        return S64_MAX;

     * rather than applying a flat bonus that treats all recent folios equally.

{

    /* Adaptive recency decay calibrated by per-folio access burstiness.
     * Burstiness = max_interval / min_interval measures access pattern variance.
     * Bursty folios (high variance, ratio > 10) → extended protection (70% boost)
     * Normal folios → proven 50% boost from Generation 40
     * Steady folios (low variance, ratio < 3) → faster decay (30% boost)

    u64 time_since_access = now - meta->last_access_ts;

    s64 burstiness = 1;  /* default: normal (non-bursty) */
    if (meta->interval_minmax.min_val > 0 && meta->interval_minmax.max_val > 0) {
