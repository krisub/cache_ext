<DESCRIPTION>
The current sequential vs random classification is too aggressive and hurts performance. The issue is that the inter_arrival threshold (50000ns = 50us) is too tight and the random-access penalty (1500 vs 5000) is too harsh.

This edit refines the classification logic by:
1. Enabling MINMAX listener for GF_SND_CWND to track congestion window state
2. Improving the sequential-hot detection: use inter_arrival < 100us (100000ns) instead of 50us, which better captures burst patterns from sequential scans
3. Adding CWND state check: sequential scans perform better under good network conditions (high CWND), so we require cwnd_ewma > 20 segments
4. Increasing sequential-hot bonus from 6000 to 6500 to more aggressively protect these folios
5. Keeping the random-access bonus at 1500 (for high inter-arrival > 500us)
6. But importantly: keeping the default case at 5000 instead of trying to classify everything, which avoids over-penalization

This asymmetric bonus scaling (6500 for sequential-hot vs 1500 for random-access) should improve YCSB-E performance while maintaining stability on mixed workloads.
</DESCRIPTION>
