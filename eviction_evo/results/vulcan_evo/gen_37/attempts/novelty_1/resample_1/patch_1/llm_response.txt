<DESCRIPTION>
The current program's sequential vs random access classification using inter-arrival patterns caused a significant regression (5667.51 → 5223.20). We should revert this complex logic and instead implement a more targeted improvement: dual-metric congestion detection that combines loss persistence with CWND collapse ratio.

This change:
1. Enables MINMAX listener for GF_SND_CWND (in addition to existing EWMA) to track historical CWND minimum
2. Reverts the problematic sequential vs random classification logic back to the simpler per-folio heat detection from the best-performing program
3. Adds a conservative dual-metric congestion signal: when CWND_EWMA drops below 1.3x the historical CWND_MIN while losses persist, apply an additional +1500 stacking bonus on top of existing loss-triggered bonuses

This approach distinguishes transient congestion (temporary CWND drops that recover quickly) from sustained congestion (CWND stuck below historical baseline with persistent losses), providing a more reliable congestion signal without the complexity that caused the recent regression.
</DESCRIPTION>
