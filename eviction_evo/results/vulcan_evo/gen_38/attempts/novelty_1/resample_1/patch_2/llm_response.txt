<DESCRIPTION>
Implement adaptive RTT baseline tracking with dynamic threshold scaling to calibrate protection multipliers to workload-specific network conditions. This addresses the current program's weakness (score 1868.97 vs best 2090.49) where trend-based detection is too noisy.

The modification adds:
1. A static variable within EVOLVE-BLOCK to store long-term RTT baseline (EWMA with alpha=50)
2. Baseline update logic in bpf_score_fn using fixed-point arithmetic  
3. Dynamic protection scaling based on current RTT vs baseline ratio
4. Graduated multipliers: 1.0x (normal), 1.25x (elevated by 20%), 1.5x (elevated by 50%)

This combines stability (fixed thresholds worked well in prior programs scoring >2000) with adaptivity (adjusts to each workload's typical network conditions automatically). Since we can only modify EVOLVE-BLOCK content, we track baseline as a static variable updated during scoring.
