<DESCRIPTION>
Following the recommendation to integrate PACKETS_OUT congestion signal with safe unsigned arithmetic for window saturation detection. This adds a secondary network factor to improve congested workload performance.

The approach:
1. Enable SND_CWND EWMA listener to track congestion window smoothly
2. Compute congestion ratio as (PACKETS_OUT / SND_CWND) * 100 using safe unsigned arithmetic
3. Apply graduated secondary boost to network_factor: +5 for ratio > 70%, +10 for ratio > 90%
4. Use additive boost pattern to avoid compounding effects with existing RTT-based protection

This provides a complementary signal to RTT for detecting network congestion, particularly valuable during the dual_congested workload where window saturation indicates the need for stronger cache protection.
</DESCRIPTION>
