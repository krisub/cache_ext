refine_dual_metric_congestion_detection
</NAME>

<DESCRIPTION>
The current implementation of dual-metric sustained congestion detection compares CWND EWMA against the historical minimum, but this comparison may not reliably identify sustained congestion across all workloads. The performance regression from 5667.51 to 5277.58 suggests the sustained_congestion logic is triggering incorrectly or not providing the intended benefit.

The recommendation suggests using "CWND collapse ratio" more reliably. Instead of comparing current EWMA against historical minimum (which may fluctuate), we should compare against a more stable baseline. A better approach is to detect when CWND EWMA drops significantly below recent stable values while losses persist.

This change:
1. Removes the sustained_congestion check that compares against cwnd_min (which proved unreliable)
2. Instead, adds a simpler additional stacking bonus (+1000) when we detect BOTH loss persistence AND CWND staying low (below 50% of its EWMA value suggests sustained problems)
3. This keeps bonuses stacking additively as recommended
4. The conservative 1.3x ratio threshold mentioned in the recommendation is applied more carefully by requiring the CWND to be substantially depressed
</DESCRIPTION>
