<DESCRIPTION>
The recommendation highlights that making the HOT_ACCESS_THRESHOLD dynamic based on network pressure conditions should improve performance. The current program uses a fixed threshold (3), but network conditions vary significantly between dual_small_vs_large (asymmetric load, mix of speeds) and dual_congested (both clients degraded, high RTT/jitter).

The key insight: during high-pressure periods (loss, cwnd congestion, high jitter), more folios should be treated as "protective" by lowering the threshold to 2 (treating warm folios as hot). During idle periods or low-pressure phases, raise it to 4 to aggressively evict rarely-accessed pages. This extends the successful multi-factor network-aware scoring by making tier classification itself dynamic.

This change directly addresses the congested trace regression (3152.17 → 3019.52 ops/sec) by improving working set protection when the network is under stress, while maintaining aggressive eviction during good network conditions to maximize cache efficiency.

// -- Helper: compute adaptive time window based on network conditions --------
static __always_inline u64 get_adaptive_window(u64 base_ns, bool under_pressure)
{
    u64 adapted = base_ns;

    // Scale by RTT: higher RTT = longer windows (each miss is more expensive)
    // Clamp net_srtt_us to avoid overflow; assume max ~10ms RTT for scaling
    u32 rtt_clamped = (net_srtt_us > 10000000) ? 10000000 : net_srtt_us;
    adapted = adapted + (u64)rtt_clamped / 20;  // Reduce RTT scaling impact

    // If network is under pressure (loss, retrans, high jitter), increase window modestly
    if (under_pressure) {
        adapted = (adapted * 5) >> 2;  // 1.25x multiplier (was 1.5x)
    }

    return adapted;
}

// -- Helper: compute dynamic hot threshold based on network conditions -------
static __always_inline u32 get_hot_access_threshold(bool net_under_pressure, bool session_active)
{
    // Under severe pressure: lower threshold to treat more folios as hot (protective)
    if (net_under_pressure && session_active) {
        return HOT_ACCESS_THRESHOLD_PRESSURE;
    }

    // Idle session: raise threshold to aggressively evict cold folios
    if (!session_active) {
        return HOT_ACCESS_THRESHOLD_IDLE;
    }

    // Normal conditions: standard threshold
    return HOT_ACCESS_THRESHOLD_NORMAL;
}
