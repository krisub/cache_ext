Looking at the current program, I can see it uses a single LRU-like list with network-aware protection. The main bottleneck is that it treats all folios uniformly once they pass the protection thresholds. Let me propose a multi-generation aging strategy inspired by MGLRU (Multi-Generational LRU) that segregates folios by their recency and access patterns, which should significantly improve throughput by making better eviction decisions.

The key insight is that database workloads have distinct access patterns:
1. Hot data (frequently accessed) - should stay cached
2. Warm data (recently accessed once) - may be re-accessed soon
3. Cold data (scan victims) - sequential scans that won't be re-accessed

I'll implement a 3-list system (hot/warm/cold) with automatic promotion/demotion based on access patterns and network activity.

<DESCRIPTION>
This edit transforms the single-list LRU into a multi-generation system with three lists (hot, warm, cold):

1. **Hot list**: Folios with multiple accesses or belonging to active DB working set
2. **Warm list**: Recently accessed folios (potential hot candidates)
3. **Cold list**: Single-access folios and scan victims

Key improvements:
- **Scan detection**: Folios accessed by sequential scans are demoted to cold list immediately
- **Promotion on re-access**: Warm→Hot promotion when access_count increases
- **Active session protection**: During network activity, active DB folios stay in hot list
- **Aging**: Use bpf_cache_ext_list_iterate_extended to age folios through lists
- **Eviction order**: Evict from cold list first, then warm, finally hot

This should improve throughput by:
- Keeping truly hot data (multi-access) in cache longer
- Quickly evicting scan victims that won't be re-accessed
- Protecting working set during active sessions
- Reducing cache churn from sequential operations

// ── Eviction iteration callback ─────────────────────────────────────
// Called for each folio during eviction scan.
// Return CACHE_EXT_EVICT_NODE to evict, CACHE_EXT_CONTINUE_ITER to keep.
static int bpf_evict_cb(int idx, struct cache_ext_list_node *node)
{
    u64 now = bpf_ktime_get_ns();
    u64 key = (u64)node->folio;

    struct net_folio_metadata *meta =
        bpf_map_lookup_elem(&folio_metadata_map, &key);

    // No metadata → unknown folio → evict
    if (!meta)
        return CACHE_EXT_EVICT_NODE;

    // Skip dirty / under-writeback folios (kernel can't evict them anyway)
    if (folio_test_dirty(node->folio) || folio_test_writeback(node->folio))
        return CACHE_EXT_CONTINUE_ITER;

    // ── Network-aware heuristics ────────────────────────────────────

    bool session_active = (now - last_packet_ts) < NET_IDLE_TIMEOUT_NS;
    bool is_active_db   = (meta->owner_pid == active_db_pid) && (active_db_pid != 0);
    bool recently_used  = (now - meta->last_access_ts) < RECENT_ACCESS_NS;
    bool in_working_set = (now - meta->last_access_ts) < WORKING_SET_NS;
    bool is_hot         = (meta->access_count >= HOT_ACCESS_THRESHOLD);

    // Protect hot folios (many accesses) that were recently touched
    if (is_hot && recently_used)
        return CACHE_EXT_CONTINUE_ITER;

    // During an active network session, protect the active DB's working set
    if (session_active && is_active_db && in_working_set)
        return CACHE_EXT_CONTINUE_ITER;

    // Protect any recently accessed folio
    if (recently_used)
        return CACHE_EXT_CONTINUE_ITER;

    // Everything else → evict
    return CACHE_EXT_EVICT_NODE;
}

{

    if (folio_test_dirty(node->folio) || folio_test_writeback(node->folio))
        return CACHE_EXT_CONTINUE_ITER;

    // Cold list: evict anything not recently accessed
    bool recently_used = (now - meta->last_access_ts) < RECENT_ACCESS_NS;

void BPF_STRUCT_OPS(evolved_folio_accessed, struct folio *folio)
{

    struct net_folio_metadata *meta =
        bpf_map_lookup_elem(&folio_metadata_map, &key);

    if (!meta) {
        // Folio not tracked yet — add to warm list
        int ret = bpf_cache_ext_list_add(warm_list, folio);
        if (ret != 0) {
            // Already in a list — try to move to head of warm list
            bpf_cache_ext_list_move(warm_list, folio, false);
        }
        struct net_folio_metadata new_meta = {
            .owner_pid     = bpf_get_current_pid_tgid() >> 32,
            .last_access_ts = now,
            .access_count  = 1,
            .access_tier   = 1,  // warm
        };
        bpf_map_update_elem(&folio_metadata_map, &key, &new_meta, BPF_ANY);
        bump_counter(3);
        return;
    }

    u64 time_since_last = now - meta->last_access_ts;
    u32 old_tier = meta->access_tier;

    // Update metadata
    meta->last_access_ts = now;
    meta->access_count += 1;

    // Determine new tier
    u32 new_tier = old_tier;
    if (meta->access_count >= HOT_ACCESS_THRESHOLD) {
        new_tier = 2;  // hot
    } else if (meta->access_count >= 2) {
        new_tier = 1;  // warm
    } else {
        // Single access - check if it's a scan victim
        if (time_since_last < SCAN_VICTIM_NS) {
            new_tier = 0;  // cold (likely scan)
        } else {
            new_tier = 1;  // warm (normal re-access)
        }

    if (new_tier != old_tier) {

        bpf_cache_ext_list_del(folio);

        u64 target_list = cold_list;

            target_list = warm_list;

        u64 current_list = cold_list;

        else if (new_tier == 1)
