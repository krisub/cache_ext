two_tier_survivor_promotion
</NAME>

<DESCRIPTION>
The current program uses a single main_list with scoring-based eviction. This recommendation implements a secondary survivor promotion mechanism within the EVOLVE-BLOCK to reduce thrashing during sustained congestion.

The key insight is that folios which survive multiple consecutive eviction scans are likely part of the core working set and should be protected more aggressively. By tracking survival counts and applying a permanent 0.5x score multiplier to survivor-tier folios, we can:

1. Reduce cache thrashing by protecting proven working-set items
2. Apply a survivor_tier field (tracked in a companion map) to mark promoted folios
3. Reduce eviction scores for survivors by 0.5x multiplier
4. Reset survival count on each access (so only persistent cold folios accumulate survival)

This builds naturally on the current scoring mechanism without requiring list restructuring.
</DESCRIPTION>
