<DESCRIPTION>
The current program uses inter-arrival time for burst detection but doesn't effectively adapt the hot access threshold based on sustained burst vs steady-state traffic patterns. This change adds packet velocity tracking (inspired by the first program's approach but with better integration into the scoring system) to distinguish between:
1. High-velocity bursts (many packets in short time) → use lower HOT_ACCESS_THRESHOLD (2) to protect more aggressively
2. Steady-state active sessions → use standard HOT_ACCESS_THRESHOLD (3)
3. Idle sessions → use higher threshold (4)

The key improvement is computing sustained burst state per eviction scan (not per folio) and using it to adjust the frequency penalty in scoring, making hot folios even more protected during bursts without affecting the rest of the scoring logic.
</DESCRIPTION>

// -- struct_ops: evict_folios -------------------------------------------------
void BPF_STRUCT_OPS(evolved_evict_folios,
                    struct cache_ext_eviction_ctx *eviction_ctx,
                    struct mem_cgroup *memcg)
{
    bump_counter(0);
    
    // Update burst detection state before eviction scan
    u64 now = bpf_ktime_get_ns();
    u64 time_since_check = (now > last_burst_check_ts) ? (now - last_burst_check_ts) : 0;
    
    // Only recompute burst state if enough time has passed (avoid per-folio overhead)
    if (time_since_check > BURST_VELOCITY_WINDOW_NS || last_burst_check_ts == 0) {
        u64 recv_delta = (net_recv_count > last_burst_check_recv_count) ?
                         (net_recv_count - last_burst_check_recv_count) : 0;
        
        // Compute velocity: packets per 100ms window
        if (time_since_check > 0) {
            u64 velocity = (recv_delta * BURST_VELOCITY_WINDOW_NS) / time_since_check;
            sustained_burst_active = (velocity >= BURST_VELOCITY_THRESHOLD);
        }
        
        // Update snapshot
        last_burst_check_ts = now;
        last_burst_check_recv_count = net_recv_count;
    }
    
    bpf_cache_ext_list_iterate(memcg, main_list, bpf_evict_cb, eviction_ctx);
}
