sustained_burst_detection
</NAME>

<DESCRIPTION>
The current burst detection relies solely on inter-arrival time (< 10ms) to identify request bursts. However, this can miss sustained high-frequency workloads where requests don't have consistent sub-10ms spacing but maintain steady high packet rates.

This change adds a secondary burst signal based on packet count velocity: if net_recv_count increases by more than 15 packets within a sliding 100ms window, we classify it as a "sustained burst". During sustained bursts, we apply stronger protection to the working set by increasing the eviction threshold by an additional 15 points (in addition to the base threshold adjustments).

This complements the existing inter-arrival based burst detection and helps distinguish between transient spikes (handled by inter-arrival detection) and sustained load (handled by packet velocity detection), improving throughput during congested scenarios while maintaining good performance on asymmetric workloads.
</DESCRIPTION>

// -- struct_ops: evict_folios -------------------------------------------------
void BPF_STRUCT_OPS(evolved_evict_folios,
                    struct cache_ext_eviction_ctx *eviction_ctx,
                    struct mem_cgroup *memcg)
{
    bump_counter(0);
    
    // Update sustained burst detection: check packet velocity over sliding window
    u64 now = bpf_ktime_get_ns();
    if (now > last_burst_velocity_check_ts) {
        u64 elapsed = now - last_burst_velocity_check_ts;
        if (elapsed > BURST_VELOCITY_WINDOW_NS) {  // Every 100ms, check packet velocity
            u64 packet_delta = (net_recv_count > prev_net_recv_count) ?
                (net_recv_count - prev_net_recv_count) : 0;
            current_sustained_burst = (packet_delta > BURST_VELOCITY_THRESHOLD);
            prev_net_recv_count = net_recv_count;
            last_burst_velocity_check_ts = now;
        }
    } else if (last_burst_velocity_check_ts == 0) {
        // First invocation: initialize velocity tracking
        prev_net_recv_count = net_recv_count;
        last_burst_velocity_check_ts = now;
    }
    
    bpf_cache_ext_list_iterate(memcg, main_list, bpf_evict_cb, eviction_ctx);
}
